# Сборка Android

Нужны компьютер x86_64, Docker, JDK 17+ и Android SDK с платформой 36. Задайте `JAVA_HOME` и `ANDROID_HOME`.

Из корня репозитория:

```powershell
./android/build.ps1
```

Linux/macOS:

```sh
sh android/build.sh
```

Скрипт собирает i2pd 3.0.0, agg-tunnel и i2pmux для ARM64 и x86_64, затем APK. Результат: `dist/multipath-i2p.apk` и `dist/multipath-i2p-x86_64.apk`.

Для одной архитектуры: `./android/build.ps1 -Abis arm64-v8a` или `ABIS=arm64-v8a sh android/build.sh`.

Если нативные компоненты уже собраны и не менялись, можно добавить `-SkipNative` или `--skip-native`. Старый кэш после обновления i2pd не подойдёт.

Сохраните `android/release.jks` и `android/keystore.properties`. Без прежнего ключа обновление не установится поверх вашей сборки. Эти файлы в Git не добавляются.

[Готовые APK](https://github.com/Molzka/i2pd-multipath-outproxy/releases/tag/v1.2.0)

## Профили

Откройте «Профиль» на главном экране, чтобы добавить, переименовать или выбрать профиль. Перед переключением отключите VPN.

Для переноса нажмите на профиль и выберите «Экспортировать в файл» или «Показать QR». На другом устройстве откройте «Профили» и импортируйте JSON или отсканируйте QR.

Переносятся адрес сервера, DNS, MTU, каналы, прыжки и настройки роутера. Исключения приложений, автоподключение и ключи i2pd остаются на своём устройстве. При использовании внешнего роутера проверьте доступность его SAM-адреса на новом устройстве.

Формат JSON версии 1:

```json
{
  "type": "multipath-i2p",
  "version": 1,
  "name": "Мой сервер",
  "server": "адрес.b32.i2p",
  "links": 16,
  "hops": 3,
  "dns": "1.1.1.1",
  "mtu": 1500,
  "router": "builtin",
  "sam": "127.0.0.1:7656"
}
```

Замените адрес на настоящий. QR содержит этот JSON в ссылке `multipath://profile?data=...`, закодированный Base64url. Поддерживается до 32 профилей, размер импортируемого файла — до 16 КБ. Не публикуйте профиль: отдельного пароля у сервера нет.

Если импорт отклонён, проверьте версию формата, `.b32.i2p`-адрес и допустимые значения: 8/16/24/32 канала, 1–3 прыжка, MTU 1280/1400/1500. При ошибке QR используйте JSON-файл.

## При потере соединения

При потере сети VPN остаётся включён. Если появляется «Трафик заблокирован», повторите подключение или отключите VPN вручную. Исключённые приложения этой блокировкой не защищены.

Для блокировки трафика при остановке самого приложения откройте «Защита в настройках Android» и включите «Постоянная VPN» и «Блокировать соединения без VPN». На Android 8–9 проверяйте состояние блокировки в системных настройках. В этом режиме исключённые приложения и внешний I2P-роутер теряют доступ к сети — используйте встроенный роутер.
